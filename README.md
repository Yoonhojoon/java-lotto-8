# java-lotto-precourse

## 기능 구현 목록
### 설계
- [ ] `Application`에서 실행 흐름만 조립하고, 입출력/도메인 분리 (Controller/Service/Domain)
- [ ] `Lotto`는 불변 객체로 유지하고 일급 컬렉션 적용 (numbers 불변, 정렬 보장)
- [ ] `LottoTicket`(한 장), `LottoBundle`(여러 장) 혹은 컬렉션 래퍼로 책임 분리
- [ ] `WinningLotto` (당첨 번호 + 보너스) 모델 추가
- [ ] `Rank`를 `enum`으로 구현(등수별 일치 개수/보너스 여부/상금 보유)

### 입력
- [ ] 구매 금액 입력 받기 (`Console.readLine`) 및 1,000원 단위 검증
- [ ] 당첨 번호 입력 받기(쉼표 구분) 및 숫자/범위/중복 검증
- [ ] 보너스 번호 입력 받기 및 숫자/범위/중복/당첨 번호와 중복 금지 검증
- [ ] 잘못된 입력 시 `IllegalArgumentException` 발생, "[ERROR]" 메시지 출력 후 해당 단계부터 재입력

### 로또 발행
- [ ] 구매 금액으로 발행 매수 계산 (1,000원/장)
- [ ] `Randoms.pickUniqueNumbersInRange(1, 45, 6)` 활용해 중복 없는 번호 6개 생성
- [ ] 각 로또 번호 오름차순 정렬 보장
- [ ] 발행된 로또 묶음 보관

### 검증 (공통)
- [ ] 로또 번호 개수 6개 확인 (`Lotto` 생성자 유효성 포함)
- [ ] 각 번호 범위 1~45 검증
- [ ] 번호 중복 금지 검증
- [ ] 금액: 정수, 음수/0 금지, 1,000으로 나누어떨어짐 검증

### 당첨 판단
- [ ] 사용자가 보유한 각 로또와 당첨 번호 일치 개수 계산
- [ ] 보너스 번호 일치 여부 판정
- [ ] `Rank` 결정 로직 구현 (6개=1등, 5+보너스=2등, 5=3등, 4=4등, 3=5등, 나머지 미당첨)
- [ ] 등수별 당첨 개수 집계

### 수익률 계산
- [ ] 등수별 상금 합산으로 총 수익 계산
- [ ] 수익률 = (총 수익 / 총 구매 금액) * 100
- [ ] 소수점 둘째 자리에서 반올림하여 출력 형식(예: 62.5%) 맞춤

### 출력
- [ ] "N개를 구매했습니다." 및 각 로또 번호(오름차순) 출력
- [ ] 당첨 통계 제목/구분선 출력
- [ ] 등수별 결과를 요구 형식 그대로 출력
- [ ] 총 수익률 출력 형식 준수

### 예외 및 메시지 정책
- [ ] 모든 사용자 입력 예외는 `IllegalArgumentException` 또는 `IllegalStateException` 사용
- [ ] 에러 메시지는 반드시 "[ERROR] "로 시작
- [ ] 예외 발생 시 프로그램 종료 없이 해당 단계부터 재입력

### 프로그래밍 규칙 반영(2주 차 공통 피드백 포함)
- [ ] 메서드 길이 15라인 이하, 단일 책임 유지
- [ ] indent depth 2 이내, `else`, `switch/case`, 3항 연산자 사용 금지
- [ ] 원시값 포장/일급 컬렉션 적용으로 검증 로직 응집
- [ ] 도메인 로직에서 UI(Console, System.out) 분리 (UI 테스트 제외)
- [ ] 불변/가시성/캡슐화 준수, 컬렉션 불변화
- [ ] `enum` 적극 활용(`Rank`, 필요 시 메시지/가격 상수화)

### 테스트 (JUnit5 + AssertJ)
- [ ] `Lotto` 생성 유효성 테스트(개수/중복/범위)
- [ ] 발행기 테스트(개수, 정렬, 범위)
- [ ] `WinningLotto` 유효성 및 보너스 중복 금지 테스트
- [ ] `Rank` 결정 로직 파라미터라이즈드 테스트(일치 수/보너스 조합)
- [ ] 수익률 계산 테스트(반올림 규칙 포함)
- [ ] 예외 메시지 형식 테스트("[ERROR]" 접두어)
